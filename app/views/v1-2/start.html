Vaccinate or test cattle to control bovine TB

Use this service if you have been invited to join the bovine TB testing and vaccination scheme.

Use this service if you are:

  • an Official Veterinarian (OV) or qualified APHA officer
  • an approved tuberculin tester
  • an approved tuberculosis vaccinator

and have been invited by Defra to vaccinate or test cattle.

You can use this service to:

  • prepare a list of cattle to vaccinate or test for bovine TB
  • report vaccinations you have completed
  • report skin test results

Before you start

You will need the country parish holding number (CPH), farm name or postcode, or an ear tag number for cattle.
