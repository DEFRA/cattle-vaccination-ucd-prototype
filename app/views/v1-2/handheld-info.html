Using a handheld device

This service does not send lists directly to handheld devices. Instead, it provides an API that handheld systems and other farm-software providers can connect to so the data is available inside their own software.

If you already use a handheld

Check the system that came with your handheld, or contact your device provider, to find out whether they are connected to this service. If they are, the list will appear in their software once they are set up to receive it.

If you do not use a handheld

You can still take the list to the visit by downloading a printable PDF or a spreadsheet (CSV).
