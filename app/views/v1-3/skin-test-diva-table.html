SICCT uses the same threshold model as the server-side rules engine in app/helpers/sicctInterpretation.js (see BASE_THRESHOLDS there); the client-side mirror is a thin copy so the on-screen result matches the value that will actually be stored on submit. DIVA (bovine increase): < 2 mm → Negative 2–4 mm → Inconclusive ≥ 4 mm → Positive (Reactor) SICCT (bovine - avian increase), standard interpretation: diff ≤ 0 → Pass (negative) diff = 1 → Inconclusive diff = 2 → Severe reactor (inconclusive band, would be a reactor under severe interpretation) diff ≥ 3 → Reactor (positive) PROTOTYPE thresholds – must be validated against the official TB64 / SICCT matrix before production use. ---------------------------------------------------------------- #} {% endblock %}
