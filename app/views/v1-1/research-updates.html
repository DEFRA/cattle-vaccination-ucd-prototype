V2

Updates based on research

Round 1 of alpha research (April 2026) tested the V1 vaccination prototype with five vets (4 APHA, 1 OV) in 45–50 minute semi-structured interviews. The findings below shaped what's in V2. Quotes are taken verbatim from the report.

Let vets record cattle in whichever order they want

Round 1 recommendation: "Allow for flexibility of order in recording those vaccinated vs not, people tackle in different orders, and our prototype is prescriptive of vax first, followed by not vax."

What changed in V2: a new "How do you want to record the cattle?" page lets the vet choose between recording the vaccinated cattle first or the cattle that weren't vaccinated first. The downstream flow follows whichever option they pick.

Affects: /v1-1/vaccination-approach · /v1-1/select-vaccinated-animals

User need: as a vet, I need to mark that a cattle has received a vaccine, so that it can be recorded, and information obtained in the future.

Let vets add cattle that weren't on the original list

Round 1 recommendation: "Allow for functionality / space to add additional cattle that are presented on the day (vax and test)" and "Ability to add cattle that weren't on the original list".

What changed in V2: an "Add a cattle" option in the report flow so a newly tagged calf or an animal that wasn't on the printed list can still be recorded.

Affects: /v1-1/skin-test-add-another · /v1-1/skin-test-confirmation

User need: as a vet, I need to have the ability to add a cattle that is not listed on the test sheet, so that I can keep a track of cattle presented, to follow up / add to the system.

Space for batch numbers on the printed list

Round 1 finding: "Identified at this point there is missing space for the batch no."

What changed in V2: the printable list now has empty boxes the vet can write batch numbers into by hand on the day of the visit.

Affects: /v1-1/skin-test-list · /v1-1/download-list

User need: as a vet, I need to be able to add a comment / note to a cattle, so that I can record important information in addition to test / vaccine recording.

Same sort / ordering options on the record page as the prepare page

Round 1 recommendation: "Provide the same sorting/ordering options on the record page as the prepare cattle page."

What changed in V2: the record-cattle table uses the same sort options (ear tag, age, sex) the vet chose when preparing the list, so the order doesn't change between the two views.

Affects: /v1-1/select-vaccinated-animals · /v1-1/skin-test-list

User need: as a vet, I need to quickly find an ear tag number, so that I can see relevant information and allow me to carry out work quickly for the correct cattle.

Reduce the number of printed pages

Round 1 emerging need: "Increased pages to take out increases effort to manage paperwork on site" and "To see how many pages their current view will generate."

What changed in V2: a "Cattle on each page" setting (20, 30 or 40) lets the vet pick a denser layout so fewer A4 sheets need to be carried onto the farm.

Affects: /v1-1/skin-test-list · /v1-1/download-list

User need: as a vet, I need to quickly find an ear tag number, so that I can see relevant information and allow me to carry out work quickly for the correct cattle.

Send a report to the farmer

Round 1 recommendation: "Send report to farmer perhaps shouldn't be optional". The Round 1 findings also noted "Positive reaction to support providing livestock owner with medicine information for their record."

What changed in V2: a "Send a report to the farmer" link is prominently surfaced on the report-submitted page so the vet remembers to share medicine information with the livestock owner.

Affects: /v1-1/report-submitted · /v1-1/skin-test-submitted

Bold last 4 ear-tag digits and a DUP marker for duplicates

Round 1 findings: "Last four digits in bold/box is received positively to help scan numbers" and "DUP (duplicate) tag received positively to avoid mistakes logging wrong info against wrong number (frequent)".

What changed in V2: the printed list emphasises the last 4 digits of each ear tag and adds a DUP flag to animals on the same farm whose last 4 digits clash, so the vet can tell them apart at a glance.

Affects: /v1-1/skin-test-list · /v1-1/download-list

User need: as a vet, I need to quickly find an ear tag number, so that I can see relevant information and allow me to carry out work quickly for the correct cattle.

Show ages in months rather than just DOB

Round 1 finding: "Ages of the cattle in months was positively received, and felt it would help them identify eligibility easier than a d.o.b."

What changed in V2: cattle list views include the age (in months) so the vet can spot eligibility at a glance.

Affects: /v1-1/skin-test-list · /v1-1/prepare-skin-test-untested

User need: as a vet, I need to know if a cattle is eligible for test, so that I can adhere to policy about giving the TB test. Also: to quickly identify cattle that are NOT eligible, so that I can discount them.

Source

bTB Cattle Vaccination Alpha Research Report Round 1 · Erin Gray, Lead User Research
