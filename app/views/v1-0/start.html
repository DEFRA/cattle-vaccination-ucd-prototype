Prepare and do farm visits

Prepare cattle lists for farm visits, manage work orders and report animal health work.

You can use this service to:

  • prepare a list for vaccination, TB testing or both
  • view open work orders
  • report vaccinations or TB tests after a visit

Before you start

You need the county parish holding number (CPH), farm name or an ear tag for the herd or animal you want to work with.
