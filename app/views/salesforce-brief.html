Vaccination data in Salesforce – prototype

Business-need led

A prototype exploring how vaccination data is searched, checked, edited and viewed in Salesforce.

This is a business-need-led set of features — it describes what the organisation needs the system to do, rather than starting from researched user needs. It should be tested against real user needs before it is taken forward.

{# -------------------------------------------------------- #}

What's in the prototype

Multi ear tag search

Search for several animals in one go by entering more than one ear tag number, rather than looking each one up separately.

Vax checker

Check the current vaccination status of an animal or a herd — for example whether an animal is vaccinated, unvaccinated, or overdue revaccination.

Edit vax data

Amend or correct vaccination details that have already been recorded against an animal or herd.

Vax history

View the vaccination history for an animal or herd — what was given, when, and by whom.

{# -------------------------------------------------------- #}

A note on where these come from

These features answer a business need, not a user need. That is worth stating plainly: they are driven by what the organisation wants the system to do, and have not been grounded in user research. Before building them out, they should be validated with the people who would actually use them, so the design starts from a real user need rather than assuming the business framing is the right one.
